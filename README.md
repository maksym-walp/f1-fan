## Вступ

Python - це потужна мова програмування, яка чудово підходить для вирішення різноманітних завдань.

Давайте спочнемо з основ. Python - це мова, яка відома своєю простотою і легкістю вивчення. Однак, щоб стати справжнім експертом у програмуванні на Python, вам потрібно ретельно ознайомитися з правилами написання коду.

Одним з основних правил є використання відступів для позначення блоків коду. У Python використовуються пробіли або табуляція (рекомендовано використовувати 4 пробіли) для відступів. Неправильний відступ може призвести до помилок у вашому коді.

Також важливо дотримуватися правил стилізації коду, які визначені в офіційному керівництві PEP 8. Це включає в себе правила для неймінгу змінних, використання пробілів та розмірів рядків коду.

Давайте розглянемо приклад:

```python
def welcome_message(name):
    """Функція для виведення вітального повідомлення."""
    message = f"Вітаємо, {name}!"
    print(message)

name = input("Введіть ваше ім'я: ")
welcome_message(name)
```
У цьому прикладі ми використовуємо правильні відступи, неймінг змінних в стилі snake_case, та додали коментарі для пояснення функції. Це допомагає зробити код більш зрозумілим і підтримуваним.

Звісно, Python має безліч корисних бібліотек і модулів для розв'язання різних завдань. Ми також будемо вивчати як їх використовувати та розвивати ваші навички програмування на цій чудовій мові.

## Освновті типи та конструкції

Є багато конструкцій та типів даних для створення різноманітних програм. Нижче наведено опис деяких основних конструкцій та типів даних в Python з прикладами коду та детальними поясненнями.

Змінні (Variables) використовуються для зберігання та маніпулювання даними. Вони можуть мати різні типи даних, і тип динамічно визначається під час присвоєння значення змінній.

### Оператори (арифметичні, порівняння, логічні)

В Python існують різні типи операторів, які дозволяють вам виконувати різні операції зі змінними та значеннями. Основні типи операторів включають арифметичні, порівняння та логічні. Ось докладний огляд кожного з них:

**Арифметичні оператори**:
1. `+` (додавання): Додає два числа разом.
2. `-` (віднімання): Віднімає одне число від іншого.
3. `*` (множення): Перемножує два числа.
4. `/` (ділення): Ділить одне число на інше.
5. `%` (модуль або залишок): Повертає залишок від ділення першого числа на друге.
6. `**` (піднесення до степеня): Підносить перше число до степеня, заданого другим числом.
7. `//` (цілочисельне ділення): Повертає цілу частку від ділення двох чисел.

**Порівняння оператори**:
1. `==` (рівність): Порівнює два значення на рівність.
2. `!=` (нерівність): Перевіряє, чи два значення не рівні.
3. `<` (менше): Перевіряє, чи перше число менше другого.
4. `>` (більше): Перевіряє, чи перше число більше другого.
5. `<=` (менше або рівне): Перевіряє, чи перше число менше або рівне другому.
6. `>=` (більше або рівне): Перевіряє, чи перше число більше або рівне другому.

**Логічні оператори**:
1. `and` (логічне І): Повертає `True`, якщо обидва вирази є `True`.
2. `or` (логічне АБО): Повертає `True`, якщо хоча б один із виразів є `True`.
3. `not` (логічне НЕ): Повертає інверсію значення виразу.

**Приклади використання операторів**:

```python
# Арифметичні оператори
x = 10
y = 5
addition_result = x + y  # addition_result = 15
subtraction_result = x - y  # subtraction_result = 5
multiplication_result = x * y  # multiplication_result = 50
division_result = x / y  # division_result = 2.0
modulo_result = x % y  # modulo_result = 0
exponentiation_result = x ** y  # exponentiation_result = 100000

# Порівняння оператори
a = 7
b = 3
equals = a == b  # equals = False
not_equals = a != b  # not_equals = True
less_than = a < b  # less_than = False
greater_than = a > b  # greater_than = True
less_or_equal = a <= b  # less_or_equal = False
greater_or_equal = a >= b  # greater_or_equal = True

# Логічні оператори
p = True
q = False
logical_and = p and q  # logical_and = False
logical_or = p or q  # logical_or = True
logical_not = not p  # logical_not = False
```

Оператори дозволяють вам виконувати різноманітні обчислення, порівнювати значення та контролювати потік програми за допомогою умовних виразів. Вони є важливою складовою будь-якої мови програмування.

### Цілі числа (int)

Цілі числа (int) є одним з типів даних в мові програмування Python, який використовується для представлення цілих чисел без десяткової частини. Ось докладний огляд цілих чисел в Python:

1. **Оголошення цілих чисел**:
   - Цілі числа можна оголосити безпосередньо в коді, наприклад:

   ```python
   x = 5
   y = -10
   z = 0
   ```

   У цьому прикладі `x`, `y`, та `z` - це змінні, які містять цілі числа 5, -10, та 0 відповідно.

2. **Властивості цілих чисел**:
   - Цілі числа у Python мають кілька важливих властивостей:
     - Вони можуть бути додатніми (+), від'ємними (-), або нулем (0).
     - Цілі числа не мають обмеження на розмір, тобто вони можуть бути дуже великими або дуже малими числами.
     - Можуть використовуватися для виконання математичних операцій, таких як додавання, віднімання, множення, та ділення.

3. **Операції з цілими числами**:
   - Цілі числа підтримують всі стандартні математичні операції, такі як:
     - Додавання (`+`): `x + y`
     - Віднімання (`-`): `x - y`
     - Множення (`*`): `x * y`
     - Ділення (`/`): `x / y` (результат - число з плаваючою комою)
     - Цілочисленне ділення (`//`): `x // y` (результат - ціле число)
     - Остача від ділення (`%`): `x % y`
     - Піднесення до ступеня (`**`): `x ** y`

4. **Тип `int` в Python**:
   - Цілі числа в Python є об'єктами типу `int`. Вони є не змінними (immutable), що означає, що значення цілих чисел не можна змінити після їхнього створення.

5. **Приклади використання**:
   - Цілі числа використовуються для різних завдань, таких як робота зі змінними, лічильники, індекси списків і кортежів, обчислення значень у математичних формулах, генерація випадкових чисел, тощо.

6. **Типові операції з рядками**:
   - Ось деякі типові операції з цілими числами в Python:

   ```python
   x = 10
   y = 3

   # Додавання
   result = x + y  # Результат: 13

   # Віднімання
   result = x - y  # Результат: 7

   # Множення
   result = x * y  # Результат: 30

   # Ділення
   result = x / y  # Результат: 3.3333333333333335 (число з плаваючою комою)

   # Цілочисленне ділення
   result = x // y  # Результат: 3 (ціле число)

   # Остача від ділення
   result = x % y  # Результат: 1
   ```

Цілі числа в Python є важливим типом даних, який використовується для числових обчислень у програмах, і вони мають широкий спектр застосувань в різних сферах програмування.

### Дійсні числа (float)

Дійсні числа (float) є типом даних в мові програмування Python, який використовується для представлення чисел з плаваючою комою, тобто чисел з десятковою частиною. Ось докладний огляд дійсних чисел в Python:

1. **Оголошення дійсних чисел**:
   - Дійсні числа можна оголосити за допомогою десяткових роздільників (крапка) або наукової нотації (з експонентою), наприклад:

   ```python
   x = 3.14
   y = -0.5
   z = 1e-3  # Це еквівалентно 0.001
   ```

   У цьому прикладі `x`, `y` та `z` - це змінні, які містять дійсні числа.

2. **Властивості дійсних чисел**:
   - Дійсні числа в Python можуть бути додатніми (+), від'ємними (-) або нулем (0).
   - Вони можуть мати десяткову частину, наприклад, `3.14`.
   - Можуть представляти дуже великі або дуже малі значення, включаючи дробові числа.

3. **Точність дійсних чисел**:
   - Важливо враховувати, що дійсні числа в Python мають обмежену точність через обмежену кількість бітів для представлення чисел з плаваючою комою. Це може призвести до апроксимацій та помилок округлення у складних математичних операціях.

4. **Операції з дійсними числами**:
   - Дійсні числа підтримують всі стандартні математичні операції, такі як:
     - Додавання (`+`): `x + y`
     - Віднімання (`-`): `x - y`
     - Множення (`*`): `x * y`
     - Ділення (`/`): `x / y`
     - Піднесення до ступеня (`**`): `x ** y`
     - Квадратний корінь (`math.sqrt(x)`): `import math; result = math.sqrt(x)`
     - Округлення (`round(x, n)`): `result = round(x, 2)` (зокруглення до 2 знаків після коми)

5. **Тип `float` в Python**:
   - Дійсні числа в Python є об'єктами типу `float`. Вони також є не змінними (immutable), що означає, що значення дійсних чисел не можна змінити після їхнього створення.

6. **Приклади використання**:
   - Дійсні числа використовуються для представлення десяткових значень у програмах. Вони широко використовуються для обчислень, обробки даних з дробовою частиною, створення графіків, моделювання, роботи з сенсорами та багатьма іншими задачами, де точність чисел з плаваючою комою важлива.

7. **Точність дійсних чисел**:
   - У зв'язку з обмеженою точністю дійсних чисел, завжди розглядайте апроксимацію та помилки округлення, особливо при порівнянні дійсних чисел на рівність.

Основна різниця між цілими числами (int) та дійсними числами (float) полягає у тому, що цілі числа представляють цілі числа без десяткової частини, тоді як дійсні числа мають десяткову частину і можуть представляти дробові значення. У багатьох випадках вибір між цілими числами та дійсними числами залежить від природи завдання та потреб вашого програмного рішення.

### Стрічки (str)

Стрічки (str) - це тип даних в мові програмування Python, який використовується для представлення текстової інформації. Стрічки є одним із найпоширеніших та найважливіших типів даних у програмуванні. Ось докладний огляд стрічок в Python:

1. **Оголошення стрічок**:
   - Стрічки можна оголошувати, використовуючи одинарні (' '), подвійні (" "), або потрійні подвійні (""" """ або ''' ''') лапки. Приклади:

   ```python
   single_quoted = 'Це одинарна лапка'
   double_quoted = "Це подвійна лапка"
   triple_quoted = """Це потрійна лапка"""
   ```

   Також можна використовувати escape-послідовності для вставки спеціальних символів, наприклад, `\n` для переведення рядка.

2. **Властивості стрічок**:
   - Стрічки можуть містити будь-який текст, включаючи літери, цифри, символи пунктуації та пробіли.
   - Вони можуть бути порожніми або містити нуль або більше символів.
   - Python підтримує Unicode, тобто ви можете використовувати символи з різних мов та символи зі спеціальних наборів.

3. **Індексація та зрізи стрічок**:
   - Стрічки індексуються, тобто кожен символ у стрічці має свій номер (індекс). Індекси починаються з 0.
   - Можна отримати доступ до окремого символу за його індексом: `my_string[0]` поверне перший символ.
   - Зрізи дозволяють отримати підрядок зі стрічки. Наприклад, `my_string[1:4]` поверне підрядок з 2-го по 4-й символ.
   - Стрічки є не змінними (immutable), тобто після створення їхнього значення неможливо змінити.

4. **Операції зі стрічками**:
   - Python підтримує багато операцій зі стрічками, такі як конкатенація (`+`), повторення (`*`), отримання довжини (`len()`), переведення у верхній або нижній регістр (`upper()`, `lower()`), пошук підрядків (`in`, `not in`), отримання індексу підрядка (`find()`, `index()`), заміна (`replace()`), розділення (`split()`), об'єднання (`join()`) і багато інших.

5. **Форматування стрічок**:
   - Python має кілька способів форматування стрічок, таких як `%` оператор, метод `str.format()`, та f-стрічки (f-strings), що вводяться за допомогою префіксу `f`. Наприклад:

   ```python
   name = "Анна"
   age = 30
   formatted_str = f"Мене звати {name} і мені {age} років."
   ```

   Вирази в фігурних дужках `{}` будуть автоматично замінені на значення змінних.

6. **Методи стрічок**:
   - Python надає багато вбудованих методів для роботи зі стрічками, таких як `strip()`, `split()`, `replace()`, `join()`, `count()`, `startswith()`, `endswith()` і багато інших.

7. **Інтерполяція стрічок**:
   - Python дозволяє вбудовувати значення змінних у стрічки за допомогою літералів ф-стрічок (f-strings) або методу `str.format()`. Це дозволяє створювати динамічні стрічки зі змінними значеннями.

8. **Рядкові літерали (raw strings)**:
   - Python також підтримує рядкові літерали, які вказують, що всі спеціальні символи в стрічці, такі як `\n` або `\t`, повинні розглядатися як звичайні символи, а не як ескейп-послідовності. Для цього використовується префікс `r`. Наприклад: `raw_str = r"C:\Program Files"`

Стрічки в Python є незамінною частиною програмування, оскільки вони використовуються для роботи з текстом, вводу та виводу, форматування даних та багатьма іншими завданнями. Вони надають можливість представляти та опрацьовувати текстову інформацію в різних форматах.


### Умовні конструкції (if-elif-else)

Умовні конструкції в Python (if-elif-else) дозволяють виконувати різні блоки коду в залежності від заданого умовного виразу. Основна структура умовної конструкції виглядає так:

```python
if умова_1:
    # Код, який виконується, якщо умова_1 True
elif умова_2:
    # Код, який виконується, якщо умова_1 False і умова_2 True
else:
    # Код, який виконується, якщо обидві умови False
```

Давайте розглянемо приклади використання умовних конструкцій:

```python
# Приклад 1: Проста умовна конструкція
age = 25
if age < 18:
    print("Ви несовершеннолетній")
else:
    print("Ви дорослий")

# Приклад 2: Умовна конструкція з elif
score = 85
if score >= 90:
    print("Відмінник")
elif score >= 80:
    print("Добре")
elif score >= 70:
    print("Задовільно")
else:
    print("Не вдалося")

# Приклад 3: Умовна конструкція з вкладеною умовною конструкцією
temperature = 28
if temperature > 30:
    print("Гаряче")
    if temperature > 35:
        print("Жарко")
elif temperature < 20:
    print("Холодно")
else:
    print("Приємна погода")

# Приклад 4: Логічні операції умов
x = 5
y = 10
if x > 0 and y > 0:
    print("Обидва числа додатні")

# Приклад 5: Перевірка наявності елементу у списку
fruits = ["яблуко", "груша", "апельсин"]
if "яблуко" in fruits:
    print("Яблуко є у списку")
```

Умовні конструкції дозволяють вам контролювати хід виконання вашої програми на основі різних умов. Вони використовуються для прийняття рішень та визначення поведінки програми в різних ситуаціях.

### Цикли (for, while)

У Python існують два основних види циклів: цикл `for` і цикл `while`. Вони дозволяють виконувати певний блок коду декілька разів з різними умовами. Давайте розглянемо кожен з них.

#### Цикл `for`

Цикл `for` використовується для ітерації (перебору) через послідовність об'єктів, такі як список, кортеж, рядок або іншу ітерабельну структуру даних. Основний синтаксис циклу `for` виглядає так:

```python
for змінна in послідовність:
    # Код, який виконується для кожного елемента послідовності
```

Давайте розглянемо приклади використання циклу `for`:

```python
# Приклад 1: Перебір списку
fruits = ["яблуко", "груша", "апельсин"]
for fruit in fruits:
    print(fruit)

# Приклад 2: Перебір чисел у діапазоні
for i in range(1, 6):  # Від 1 до 5
    print(i)

# Приклад 3: Перебір символів у рядку
text = "Hello"
for char in text:
    print(char)
```

#### Цикл `while`

Цикл `while` використовується для виконання блоку коду доти, доки певна умова залишається істинною. Основний синтаксис циклу `while` виглядає так:

```python
while умова:
    # Код, який виконується, поки умова істинна
```

Давайте розглянемо приклади використання циклу `while`:

```python
# Приклад 1: Цикл, який виконується поки змінна менше 5
count = 1
while count < 5:
    print(count)
    count += 1

# Приклад 2: Введення користувача
user_input = ""
while user_input != "quit":
    user_input = input("Введіть команду (або 'quit' для виходу): ")
    print(f"Ви ввели команду: {user_input}")
```

Цикли `for` і `while` дозволяють вам створювати повторювані структури для виконання певного коду з певними умовами. Вибір між циклами залежить від конкретного завдання, яке ви хочете вирішити.

### Списки (list)

Список (list) в Python є одним з основних типів даних і використовується для зберігання колекції елементів. Список є змінним (mutable) та дозволяє зберігати елементи різних типів даних. Основні риси списків включають:

1. **Зберігання елементів:** Ви можете зберігати більше одного елемента у списку. Елементи можуть бути числами, рядками, іншими списками, і так далі.

2. **Змінність (Mutable):** Списки можна змінювати, додавати, видаляти та змінювати елементи.

3. **Індексація:** Елементи списку індексуються, починаючи з 0. Ви можете отримати доступ до елементів за допомогою індексів.

4. **Змішані типи даних:** Списки можуть містити елементи різних типів даних. Наприклад, список може містити цілі числа, рядки та булеві значення.

5. **Довжина списку:** Ви можете отримати довжину списку за допомогою функції `len()`, яка показує кількість елементів у списку.

6. **Операції зі списками:** Списки підтримують операції, такі як додавання, видалення, злиття, розширення та інші.

Ось приклади створення, роботи зі списками та виконання різних операцій:

```python
# Створення списку
my_list = [1, 2, 3, 4, 5]

# Додавання елементу в кінець списку
my_list.append(6)  # my_list = [1, 2, 3, 4, 5, 6]

# Доступ до елементів списку за індексом
first_element = my_list[0]  # Перший елемент (1)
last_element = my_list[-1]  # Останній елемент (6)

# Зміна значення елементу
my_list[2] = 10  # my_list = [1, 2, 10, 4, 5, 6]

# Видалення елемента за значенням
my_list.remove(4)  # my_list = [1, 2, 10, 5, 6]

# Видалення елемента за індексом
del my_list[1]  # my_list = [1, 10, 5, 6]

# Довжина списку
length = len(my_list)  # length = 4

# Злиття двох списків
list1 = [1, 2, 3]
list2 = [4, 5, 6]
merged_list = list1 + list2  # merged_list = [1, 2, 3, 4, 5, 6]
```

Списки використовуються для зберігання та обробки даних в багатьох програмах, і вони є важливим інструментом в Python.

### Кортежі (tuple)

Кортеж (tuple) в Python є структурою даних, яка схожа на список, але відрізняється важливою властивістю - кортежи є незмінними (immutable). Це означає, що після того, як кортеж створений, ви не можете змінювати його елементи. Основні риси кортежів включають:

1. **Зберігання елементів:** Кортежи використовуються для зберігання колекції елементів, які можуть бути різних типів даних.

2. **Незмінність (Immutable):** Елементи кортежу не можна змінювати після його створення. Це робить кортежі підходящими для зберігання даних, які не повинні змінюватися.

3. **Індексація:** Елементи кортежу індексуються, починаючи з 0, і ви можете отримати доступ до них за допомогою індексів.

4. **Змішані типи даних:** Кортежі можуть містити елементи різних типів даних.

5. **Довжина кортежу:** Ви можете отримати довжину кортежу за допомогою функції `len()`, яка показує кількість елементів у кортежі.

6. **Розпакування кортежу:** Ви можете розпакувати значення кортежу у змінні.

7. **Операції з кортежами:** Кортежі підтримують операції, такі як з'єднання кортежів, множення кортежу на число і інші.

Ось приклади створення, роботи з кортежами та виконання різних операцій:

```python
# Створення кортежу
my_tuple = (1, 2, 3, 'Python', 'Кортеж')

# Доступ до елементів кортежу за індексом
first_element = my_tuple[0]  # Перший елемент (1)
second_element = my_tuple[1]  # Другий елемент (2)

# Розпакування кортежу в змінні
a, b, c, _, _ = my_tuple  # a = 1, b = 2, c = 3

# Довжина кортежу
length = len(my_tuple)  # length = 5

# Злиття двох кортежів
tuple1 = (1, 2, 3)
tuple2 = ('a', 'b', 'c')
combined_tuple = tuple1 + tuple2  # combined_tuple = (1, 2, 3, 'a', 'b', 'c')
```

Кортежі використовуються там, де важлива незмінність даних. Наприклад, вони можуть бути використані для представлення координат, дати або інших даних, які не повинні змінюватися. Кортежі є корисними для створення незмінних наборів даних, які не можна помилково змінити під час виконання програми.

### Множини (set)

Множина (set) в Python - це структура даних, яка представляє собою набір унікальних і неупорядкованих елементів. Основні характеристики множин включають:

1. **Унікальність елементів:** У множині не може бути дубльованих значень. Кожен елемент у множині є унікальним.

2. **Неупорядкованість:** Елементи множини не зберігаються в певному порядку, і ви не можете звертатися до них за допомогою індексів.

3. **Модифікованість (mutable):** Множини є змінними, тобто ви можете додавати, видаляти та змінювати елементи множини під час її використання.

4. **Хешування:** Елементи множини повинні бути хешованими, тобто вони мають бути незмінними. Такі типи даних, як числа, рядки та кортежі, підходять для використання в множинах.

5. **Операції над множинами:** Множини підтримують різні операції, такі як додавання елементів, видалення, перетин, об'єднання, віднімання та інші.

6. **Використання:** Множини корисно використовувати в задачах, де необхідно виявити унікальні значення або виконати операції, які базуються на математичних множинах.

Ось приклади роботи з множинами:

```python
# Створення множини
my_set = {1, 2, 3, 4, 5}

# Додавання елементу в множину
my_set.add(6)

# Видалення елементу з множини
my_set.remove(3)

# Перевірка наявності елементу у множині
is_present = 2 in my_set  # True

# Перетин множин
set1 = {1, 2, 3}
set2 = {3, 4, 5}
intersection = set1 & set2  # intersection = {3}

# Об'єднання множин
union = set1 | set2  # union = {1, 2, 3, 4, 5}

# Різниця множин
difference = set1 - set2  # difference = {1, 2}

# Пуста множина
empty_set = set()

# Кількість елементів у множині
length = len(my_set)

# Ітерація по елементам множини
for item in my_set:
    print(item)
```

Множини дуже корисні для оптимізації операцій пошуку та фільтрації унікальних значень у вашому коді.

### Словники (dict)

Словник (dict) в Python - це структура даних, яка представляє собою набір пар "ключ-значення" (key-value pairs). Основні характеристики словників включають:

1. **Унікальні ключі:** Кожен ключ у словнику є унікальним, тобто в словнику не може бути дублюються ключі.

2. **Неупорядкованість:** У Python версій до 3.7 словники були неупорядкованими, але починаючи з Python 3.7, вони зберігають порядок додавання ключів.

3. **Модифікованість (mutable):** Словники є змінними, тобто ви можете додавати, змінювати та видаляти пари ключ-значення під час їх використання.

4. **Хешувані ключі:** Ключі в словнику повинні бути хешованими, тобто вони мають бути незмінними, як числа або рядки.

5. **Швидкий доступ:** Ви можете швидко отримати значення за ключем, що робить словники ефективними для пошуку та індексації даних.

6. **Операції над словниками:** Словники підтримують різні операції, такі як додавання пар ключ-значення, видалення, зміна значень, ітерація, перевірка наявності ключа та інші.

7. **Використання:** Словники корисно використовувати для збереження пар "ключ-значення", таких як дані про користувачів, налаштування програми, словники, переклади та багато іншого.

Ось приклади роботи зі словниками:

```python
# Створення словника
my_dict = {
    "name": "John",
    "age": 30,
    "city": "New York"
}

# Додавання пари ключ-значення
my_dict["job"] = "Engineer"

# Доступ до значення за ключем
name = my_dict["name"]

# Перевірка наявності ключа у словнику
is_present = "city" in my_dict  # True

# Видалення пари ключ-значення
del my_dict["age"]

# Отримання ключів та значень словника
keys = my_dict.keys()
values = my_dict.values()

# Ітерація по ключам та значенням словника
for key, value in my_dict.items():
    print(key, value)
```

Словники в Python є дуже потужними та корисними структурами даних, і вони широко використовуються для організації та збереження даних у ваших програмах.

### Функції (def)

Функції є одним із основних засобів організації та структурування коду в мові програмування Python. Вони дозволяють визначити певну логічну частину коду, яку можна викликати з інших частин програми. Визначення функції починається з ключового слова `def`. Давайте розглянемо основні концепції та приклади використання функцій в Python.

### Визначення функції

Основний синтаксис визначення функції виглядає так:

```python
def назва_функції(параметри):
    # Тіло функції (блок коду)
    # ...
    return результат
```

- `назва_функції` - ім'я функції, яке ви обираєте. Ім'я повинно бути унікальним і відповідати правилам іменування змінних в Python.
- `параметри` - параметри (аргументи) функції, які можуть передаватися їй при виклику.
- `результат` - за допомогою ключового слова `return` функція може повертати значення, яке буде результатом її виконання.

#### Приклади функцій

Давайте розглянемо приклади визначення та виклику функцій:

```python
# Приклад 1: Функція без параметрів та без повернення значення
def say_hello():
    print("Привіт, світ!")

# Виклик функції
say_hello()  # Виведе "Привіт, світ!"

# Приклад 2: Функція з параметрами та поверненням значення
def add(a, b):
    result = a + b
    return result

# Виклик функції та збереження результату у змінну
sum = add(5, 3)
print("Сума:", sum)  # Виведе "Сума: 8"

# Приклад 3: Функція з параметрами за замовчуванням
def greet(name="Гість"):
    print(f"Привіт, {name}!")

# Виклик функції без параметрів
greet()  # Виведе "Привіт, Гість!"

# Виклик функції з параметром
greet("Анна")  # Виведе "Привіт, Анна!"
```

#### Основні концепції функцій

Основні концепції функцій в Python включають:

- Визначення функції за допомогою ключового слова `def`.
- Параметри (аргументи) функції - це значення, які передаються функції для обробки.
- Тіло функції - це блок коду, який визначається відступами і виконується при виклику функції.
- За допомогою `return` можна повертати результати виконання функції.
- Виклик функції здійснюється шляхом вказання її імені та передачі відповідних аргументів.

Функції дозволяють уникнути дублювання коду, полегшують зрозуміність та обслуговуваність програми, а також дозволяють структурувати код у логічні блоки, що спрощує розробку та підтримку програм. Функції також можуть бути багатократно викликані з різними аргументами, що робить їх дуже корисними для вирішення різних завдань у програмуванні.

### Класи та об'єкти (class, object)

Класи та об'єкти є однією з фундаментальних концепцій об'єктно-орієнтованого програмування (ООП) в мові програмування Python. Вони дозволяють створювати складні структури даних та взаємодіяти з ними на більш абстрактному рівні. Давайте розглянемо основні поняття та приклади використання класів та об'єктів в Python.

#### Класи

Клас є шаблоном або описом, за яким створюються об'єкти. Визначення класу починається з ключового слова `class`, за яким слідує ім'я класу та двокрапка. Ось приклад простого класу:

```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def greet(self):
        print(f"Привіт, мене звати {self.name} і мені {self.age} років.")
```

У цьому прикладі ми визначили клас `Person`, який має два атрибути (змінні): `name` і `age`, а також метод `greet`, який виводить привітання на основі цих атрибутів.

#### Об'єкти

Об'єкт є конкретним екземпляром класу. Щоб створити об'єкт, ви викликаєте конструктор класу. В Python конструктор має ім'я `__init__`, і він викликається автоматично при створенні нового об'єкта класу. Ось приклад створення об'єктів класу `Person`:

```python
# Створення об'єктів класу "Person"
person1 = Person("Анна", 25)
person2 = Person("Петро", 30)
```

У цьому прикладі `person1` і `person2` є об'єктами класу `Person`, і кожен з них має свої власні значення атрибутів `name` і `age`.

#### Методи

Методи - це функції, які визначаються в межах класу і взаємодіють з об'єктами цього класу. У прикладі класу `Person`, метод `greet` виконує операцію привітання для об'єкта типу `Person`.

#### Інкапсуляція

Інкапсуляція - це концепція, яка дозволяє обмежити доступ до певних атрибутів чи методів класу, роблячи їх закритими (private) або захищеними (protected). В Python це досягається за допомогою подвійних підкреслень перед іменами атрибутів чи методів. Наприклад, `_name` - це захищений атрибут, а `__name` - закритий.

#### Наслідування

Наслідування - це механізм, за допомогою якого клас може успадковувати атрибути та методи іншого класу. В Python клас може успадковувати інший клас, використовуючи ключове слово `class` з вказанням батьківського класу в дужках. Наслідуваний клас називається підкласом, а клас, який успадковується, - батьківським класом або суперкласом.

#### Поліморфізм

Поліморфізм - це можливість об'єктів різних класів відповідати на однакові методи. В інших словах, об'єкти можуть вести себе по-різному в залежності від їхнього класу, але вони можуть викликати однакові методи. 

Ось приклад поліморфізму:

```python
class Dog:
    def make_sound(self):
        print("Гав!")

class Cat:
    def make_sound(self):
        print("Мяу!")

def animal_sound(animal):
    animal.make_sound()

dog = Dog()
cat = Cat()

animal_sound(dog)  # Виведе "Гав!"
animal_sound(cat)  # Виведе "Мяу!"
```

У цьому прикладі об'єкти `dog` і `cat` р

ізних класів викликають однаковий метод `make_sound`, і кожен з них поводиться по-своєму.

Класи та об'єкти в Python надають можливість створювати більш організований та структурований код, а ООП є важливою концепцією в розробці програм для багатьох задач.

### Виключення (try-except)

Обробка виключень (try-except) є важливою конструкцією в Python, яка дозволяє управляти помилками та виконувати альтернативний код у випадку виникнення виключення. Основна ідея полягає в тому, що ви поміщаєте блок коду, який може викликати виключення, всередині `try` блоку, і вказуєте, яке виключення ви хочете обробити у `except` блоках. Ось загальний синтаксис:

```python
try:
    # Код, який може викликати виключення
except ExceptionType1 as e1:
    # Обробка виключення типу ExceptionType1
except ExceptionType2 as e2:
    # Обробка виключення типу ExceptionType2
else:
    # Опціональний блок else, який виконується, якщо виключення не виникло
finally:
    # Опціональний блок finally, який завжди виконується
```

Ось деякі важливі деталі стосовно обробки виключень:

1. Ви можете вказати один або декілька `except` блоків для обробки різних типів виключень. Кожен `except` блок вказує тип виключення і, якщо таке виключення виникає, код у цьому блоку виконується.

2. Ви можете використовувати ключове слово `as`, щоб присвоїти об'єкт виключення змінній. Це дозволяє вам отримувати доступ до додаткової інформації про виключення, такої як повідомлення про помилку.

3. Блок `else` є опціональним і виконується, якщо виключення не виникло в `try` блоку. Він використовується, коли ви хочете виконати код, який не пов'язаний з обробкою виключення, але повинен виконатися тільки в разі відсутності виключення.

4. Блок `finally` теж є опціональним і завжди виконується, незалежно від того, чи виникло виключення, чи ні. Він використовується, коли вам потрібно впевнитися, що певний код завжди виконується, наприклад, для звільнення ресурсів.

Ось приклад використання обробки виключень:

```python
try:
    x = 10 / 0  # Спроба ділення на нуль
except ZeroDivisionError as e:
    print(f"Помилка: {e}")  # Виведе "Помилка: division by zero"
except ArithmeticError as e:
    print(f"Арифметична помилка: {e}")
else:
    print("Все в порядку, виключення не виникло.")
finally:
    print("Завжди виконується блок finally.")
```

У цьому прикладі використано `try-except` для обробки виключення `ZeroDivisionError`, оскільки ми спробуємо здійснити ділення на нуль. Блок `else`

 не виконується, оскільки виключення виникло, а блок `finally` завжди виконується, незалежно від виникнення виключення.

### Генератори (generator)

Генератори (generators) в Python - це спеціальний тип ітераторів, які генерують значення на лету і дозволяють обробляти послідовності даних без зберігання їх у пам'яті. Генератори дуже корисні для роботи з великими об'ємами даних, оскільки вони дозволяють ефективно обробляти дані порціями.

Основними характеристиками генераторів є:

1. **Лінивість (Laziness)**: Генератори виробляють значення по одному на кожному кроці, і їхні значення не зберігаються в пам'яті в цілому. Замість цього, вони зберігають поточний стан та можуть продовжувати виробляти значення при кожному запиті.

2. **Ітерабельність (Iterability)**: Генератори можна ітерувати за допомогою циклів `for`, а також застосовувати до них інші ітераційні функції, такі як `map` і `filter`.

3. **Зручний синтаксис (Concise Syntax)**: Генератори можна визначити за допомогою спеціального синтаксису, використовуючи ключове слово `yield`. Це дозволяє створювати генератори з меншим обсягом коду порівняно зі звичайними ітераторами.

Ось приклад генератора, який створює послідовність чисел Фібоначчі:

```python
def fibonacci_generator():
    a, b = 0, 1
    while True:
        yield a
        a, b = b, a + b

# Використання генератора для отримання перших 10 чисел Фібоначчі
fib = fibonacci_generator()
for _ in range(10):
    print(next(fib))
```

У цьому прикладі функція `fibonacci_generator` є генератором, який використовує `yield` для повернення чисел Фібоначчі одне за одним при кожному виклику `next`. Це дозволяє отримувати числа Фібоначчі без зберігання всіх попередніх значень у пам'яті.

Генератори дуже корисні для обробки великих файлів, потоків даних, генерації послідовностей чисел та багатьох інших завдань, де ефективне управління пам'яттю є важливим.

### Лямбда-функції (lambda)

Лямбда-функції (або анонімні функції) в Python - це функції, які можна визначити без ключового слова `def`. Вони зазвичай використовуються для створення коротких функцій, які не потребують складних обчислень або визначень функцій великими блоками коду. Синтаксис лямбда-функцій дуже лаконічний і виглядає так:

```python
lambda arguments: expression
```

Основні особливості лямбда-функцій:

1. **Анонімність**: Лямбда-функції не мають імені і зазвичай використовуються там, де потрібно створити функцію для одноразового використання.

2. **Короткість**: Вони зазвичай короткі і призначені для вирішення простих завдань.

3. **Повернення результату**: Вони завжди повертають результат обчислення виразу.

Ось декілька прикладів використання лямбда-функцій:

```python
# Приклад 1: Проста лямбда-функція для додавання двох чисел
add = lambda x, y: x + y
result = add(3, 5)
print(result)  # Виведе 8

# Приклад 2: Лямбда-функція для сортування списку за довжиною рядків
strings = ["apple", "banana", "cherry", "date"]
strings.sort(key=lambda x: len(x))
print(strings)  # Виведе ['date', 'apple', 'cherry', 'banana']

# Приклад 3: Використання лямбда-функції у функції вищого порядку
numbers = [1, 2, 3, 4, 5]
squared = map(lambda x: x**2, numbers)
print(list(squared))  # Виведе [1, 4, 9, 16, 25]
```

Лямбда-функції корисні, коли потрібно створити невелику функцію для передачі в іншу функцію (наприклад, в функцію `map`, `filter`, `sorted` або як аргумент до інших функцій). Вони допомагають зробити код більш компактним і читабельним в деяких випадках. Однак, слід зауважити, що вони повинні використовуватися з обережністю, оскільки їх зловживання може призвести до складночитаного та неочевидного коду.
   
### Імпортування модулів (import)

Імпортування модулів у Python - це спосіб використовувати функції, класи і змінні, які знаходяться в інших файлів модулів. Модуль - це файл Python зі змінними та функціями, які можна використовувати в інших програмах. Щоб імпортувати модуль, використовується ключове слово `import`.

Основні способи імпортування модулів:

1. **Імпорт всього модуля**: Весь модуль можна імпортувати за допомогою ключового слова `import`. Наприклад:

   ```python
   import math
   print(math.pi)  # Виведе число π
   ```

2. **Імпорт конкретного імені з модуля**: Можна імпортувати лише певні функції, класи або змінні з модуля. Це зменшує простір імен і дозволяє використовувати їх без префікса імені модуля. Наприклад:

   ```python
   from math import pi
   print(pi)  # Виведе число π без зазначення імені модуля
   ```

3. **Імпорт модуля з псевдонімом**: Можна імпортувати модуль з псевдонімом (скороченим іменем), щоб зробити код більш компактним або уникнути конфлікту імен. Наприклад:

   ```python
   import numpy as np
   result = np.array([1, 2, 3])
   ```

4. **Імпорт всього модуля з псевдонімом**: Також можна імпортувати весь модуль з псевдонімом. Це корисно, коли вам потрібно використовувати багато функцій з модуля. Наприклад:

   ```python
   import pandas as pd
   data = pd.read_csv('data.csv')
   ```

5. **Умовний імпорт**: Іноді може бути корисно імпортувати модуль умовно, залежно від умови. Це використовується для оптимізації програми, щоб завантажувати модуль лише в тому випадку, якщо він дійсно потрібен. Наприклад:

   ```python
   if condition:
       import module_name
   ```

Це основні способи імпортування модулів в Python. Імпортування модулів дозволяє використовувати готовий код та бібліотеки для вирішення різних завдань без необхідності писати всю логіку з нуля.

### Робота з файлами (open, read, write)

Робота з файлами в Python дозволяє вам зчитувати і записувати дані у текстові та бінарні файли. Основні функції для роботи з файлами включають `open`, `read`, `write` та інші.

Основні операції з файлами:

1. **Відкриття файлу**: Для відкриття файлу використовується функція `open`. Вона приймає два аргументи: ім'я файлу і режим відкриття (наприклад, для читання або запису). Наприклад:

   ```python
   # Відкриття файлу для читання
   file = open('example.txt', 'r')

   # Відкриття файлу для запису (створення нового або перезапису існуючого)
   file = open('output.txt', 'w')

   # Відкриття файлу для додавання (якщо файл існує, дані додаються в кінець)
   file = open('data.txt', 'a')
   ```

2. **Читання з файлу**: Для читання вмісту файлу використовується метод `read`. Наприклад:

   ```python
   with open('example.txt', 'r') as file:
       content = file.read()
       print(content)
   ```

   Важливо відзначити, що краще використовувати контекстний менеджер `with`, який автоматично закриє файл після завершення роботи з ним.

3. **Запис в файл**: Для запису даних в файл використовується метод `write`. Наприклад:

   ```python
   with open('output.txt', 'w') as file:
       file.write('Це текст, який буде записаний в файл.')
   ```

   Зверніть увагу, що якщо файл вже існує і відкритий в режимі запису `'w'`, весь попередній вміст файлу буде видалено.

4. **Читання файлу по рядках**: Для читання файлу по рядках можна використовувати цикл `for`. Наприклад:

   ```python
   with open('example.txt', 'r') as file:
       for line in file:
           print(line)
   ```

   Це дозволяє обробляти файл по рядках, що особливо корисно для великих файлів.

5. **Додавання даних в файл**: Якщо вам потрібно додати дані в кінець існуючого файлу, використовуйте режим `'a'` при відкритті файлу:

   ```python
   with open('data.txt', 'a') as file:
       file.write('Додаткові дані')
   ```

   Це не перезапише вміст файлу, а додасть нові дані в кінець.

6. **Зчитування вмісту файлу в список рядків**: Ви також можете зчитати вміст файлу у список рядків за допомогою методу `readlines`:

   ```python
   with open('example.txt', 'r') as file:
       lines = file.readlines()
       for line in lines:
           print(line)
   ```

   Кожен рядок файлу стає окремим елементом у списку `lines`.

7. **Робота з бінарними файлами**: Вище наведені приклади стосуються текстових файлів. Для роботи з бінарними файлами (наприклад, зображеннями або архівами) використовується режим `'rb'` для читання і `'wb'` для запису.

Це загальний огляд операцій з файлами в Python. Робота з файлами важлива для зберігання та обробки даних у програмах. Не забувайте завжди закривати файли, коли завершуєте з ними роботу, або використовуйте контекстний менеджер `with`, який автоматично виконає закриття за вас.

### Управління пам'яттю (garbage collection)

Управління пам'яттю в мові програмування Python відбувається автоматично завдяки вбудованому механізму, відомому як зборщик сміття (garbage collector). Головна мета цього механізму - видалення об'єктів, які більше не використовуються в програмі, для вільного місця в пам'яті та оптимізації роботи програми.

Основні аспекти управління пам'яттю в Python:

1. **Спрощений інтерфейс**: Розробникам не потрібно явно вивільняти пам'ять після використання об'єктів. Зборщик сміття автоматично визначає, коли об'єкти можна видалити.

2. **Підрахунок посилань**: Зборщик сміття використовує підрахунок посилань для визначення, коли об'єкт стає недосяжним (тобто немає посилань на нього). Якщо немає активних посилань на об'єкт, то він вважається сміттям та підлягає видаленню.

3. **Циклічні посилання**: Зборщик сміття може впоратися навіть з об'єктами, які мають циклічні посилання, коли один об'єкт посилається на інший, і відбувається замкнута послідовність посилань. В такому випадку зборщик сміття визначає групи об'єктів, які взаємно посилаються один на одного, і видаляє їх, якщо немає зовнішніх посилань на цю групу.

4. **Модуль `gc`**: Модуль `gc` в Python надає керування збором сміття та дозволяє вимагати збору сміття вручну. Наприклад, ви можете викликати `gc.collect()` для примусового збору сміття у певний момент.

5. **Динамічна робота з пам'яттю**: Python автоматично розподіляє та вивільняє пам'ять за потреби. Це дозволяє забезпечити оптимальне використання ресурсів та попередити витоки пам'яті.

6. **Рекурсія і стек викликів**: Python обмежує глибину рекурсивних викликів за замовчуванням для захисту стеку викликів від переповнення.

Зборщик сміття є потужним механізмом, який зазвичай працює добре для більшості програм. Однак розробники повинні слідкувати за кількістю створюваних об'єктів та вибором структур даних, оскільки неправильне використання може призвести до надмірного споживання пам'яті.

Якщо потрібно вирішити конкретні питання з управлінням пам'яттю, можна використовувати інструменти, такі як модуль `gc` та профіліровщики пам'яті, щоб аналізувати та оптимізувати використання пам'яті вашої програми.

Управління пам'яттю в Python зазвичай відбувається автоматично завдяки механізму автоматичного збору сміття (garbage collection). Python використовує об'єктно-орієнтований підхід до управління пам'яттю та має вбудований сбиральник сміття, який відслідковує та видаляє об'єкти, які більше не використовуються.

Простий приклад автоматичного збору сміття в Python:

```python
import gc

# Створення об'єкта, який займає пам'ять
class MyClass:
    def __init__(self, name):
        self.name = name

# Вручну визначаємо посилання на об'єкт
obj = MyClass("Об'єкт 1")

# Завершуємо посилання на об'єкт
del obj

# Викликаємо сбиральник сміття
gc.collect()

# Тепер пам'ять, яку займав об'єкт, очищена
```

Важливо зазначити, що в більшості випадків вам не потрібно вручну втручати у процес збору сміття в Python. Сбиральник сміття працює автоматично, але іноді може бути корисним зрозуміти, як він працює, і використовувати модуль `gc` для виклику збору сміття вручну.

Більш складні випадки використання автоматичного збору сміття можуть виникнути при роботі з циклічними посиланнями або великими об'ємами даних. У таких випадках важливо слідкувати за об'єктами, які більше не використовуються, і вчасно відчищати посилання на них або викликати збір сміття вручну.

Якщо ви використовуєте сторонні бібліотеки або фреймворки, які вимагають спеціального управління пам'яттю, вам слід вивчати документацію цих інструментів для правильного використання та уникнення утечок пам'яті.

### Декоратори (decorators)

Декоратори - це потужний інструмент у Python, який дозволяє модифікувати поведінку функцій або методів класів без зміни їхнього вихідного коду. Декоратори використовуються для додавання функціональності до існуючих функцій або методів. Вони є важливою частиною парадигми програмування, відомої як метапрограмування.

Основні концепції декораторів в Python:

1. Функція-декоратор - це функція, яка приймає іншу функцію або метод як аргумент і повертає нову функцію з додатковою функціональністю. Функція-декоратор обгортає (декорує) іншу функцію і додає до неї певні дії.

2. Синтаксис декораторів: Декоратори вказуються перед визначенням функції або методу за допомогою символу "@".

3. Декоратори можна використовувати для виконання певних дій перед та/або після виклику функції, для валідації вхідних даних, для логування, кешування і багатьох інших задач.

4. Декоратори можна застосовувати не тільки до функцій, але і до методів класів.

Ось приклад простого декоратора, який логує час виконання функції:

```python
import time

# Основна функція
def some_function():
    print("Виконується основна функція")

# Декоратор для логування часу виконання
def timing_decorator(func):
    def wrapper():
        start_time = time.time()
        func()
        end_time = time.time()
        print(f"Функція виконана за {end_time - start_time} секунд")
    return wrapper

# Використання декоратора
decorated_function = timing_decorator(some_function)
decorated_function()
```

В результаті виконання цього коду функція `timing_decorator` декорує функцію `some_function`, і після виклику `decorated_function()` буде виведено час виконання функції `some_function`.

Однак у Python є зручний синтаксис для застосування декораторів за допомогою символу "@":

```python
import time

# Декоратор для логування часу виконання
def timing_decorator(func):
    def wrapper():
        start_time = time.time()
        func()
        end_time = time.time()
        print(f"Функція виконана за {end_time - start_time} секунд")
    return wrapper

# Використання декоратора за допомогою символу "@"
@timing_decorator
def some_function():
    print("Виконується основна функція")

some_function()
```

Цей синтаксис робить код більш зрозумілим та зручним для використання декораторів. Декоратори використовуються в Python для багатьох різних завдань, від логування до кешування та забезпечення безпеки. Вони дозволяють вам розділити функціональність вашого коду на окремі шари і модифікувати цей код без зміни вихідного коду функцій або методів.

### Контекстні менеджери (context managers)

Контекстні менеджери (context managers) - це механізм у Python, який дозволяє створювати та управляти контекстом виконання певного коду, такого як відкриття та закриття файлів, робота з ресурсами, що потребують очищення, або з'єднання з базами даних. Контекстні менеджери реалізовані за допомогою методів `__enter__` і `__exit__` спеціального класу.

Основні переваги контекстних менеджерів:

1. Забезпечують правильне відкриття та закриття ресурсів.
2. Гарантують виконання певних дій перед та після виконання коду в контексті.
3. Зроблюють код більш зрозумілим і безпечним.

Ось приклад використання контекстного менеджера для роботи з файлом:

```python
# Відкриття файлу в контексті
with open('example.txt', 'r') as file:
    content = file.read()
    # Виконуємо дії з файлом

# Файл буде автоматично закритий після виходу з контексту
```

У цьому прикладі `open('example.txt', 'r')` створює контекстний менеджер, який відкриває файл для читання. Після завершення блоку `with`, файл буде автоматично закритий, навіть якщо виникне виключення.

Ви також можете створювати власні контекстні менеджери за допомогою створення класу з методами `__enter__` та `__exit__`. Ось приклад простого контекстного менеджера:

```python
class MyContextManager:
    def __enter__(self):
        print("Входження в контекст")

    def __exit__(self, exc_type, exc_value, traceback):
        print("Виходження з контексту")

# Використання власного контекстного менеджера
with MyContextManager():
    print("Виконання коду в контексті")

# Виходження з контексту
```

У методі `__enter__` ви можете виконати певні підготовчі дії перед виконанням коду в контексті, а у методі `__exit__` ви можете виконати завершальні дії, а також обробку виключень, якщо вони виникають під час виконання коду в контексті.

Контекстні менеджери дуже корисні для забезпечення правильної роботи з ресурсами та для автоматизації певних операцій перед та після виконання коду в контексті.

## Виконання лабораторних робіт

`venv` (скорочено від "virtual environment") - це інструмент в Python, який дозволяє створювати та керувати віртуальними середовищами для розробки проектів. Віртуальне середовище - це ізольоване простору, в якому можна ізолювати залежності та бібліотеки для кожного проекту. Це допомагає уникнути конфліктів між версіями бібліотек та забезпечити чисте та надійне середовище для роботи.

Основні команди та дії, пов'язані з `venv`, включають:

1. **Створення віртуального середовища**:
   ```bash
   python -m venv myenv
   ```
   Де `myenv` - це назва вашого віртуального середовища. Ця команда створить ізольовану директорію, де будуть зберігатися бібліотеки та залежності для вашого проекту.

2. **Активація віртуального середовища**:
   Після створення ви можете активувати своє віртуальне середовище:
   - На Windows:
     ```bash
     myenv\Scripts\activate
     ```
   - На macOS та Linux:
     ```bash
     source myenv/bin/activate
     ```
   Після активації ваш командний рядок буде мати префікс із назвою вашого віртуального середовища, що вказує на активоване середовище.

3. **Використання віртуального середовища**:
   В активованому віртуальному середовищі ви можете встановлювати бібліотеки та пакети за допомогою `pip`, і вони будуть доступні лише для цього середовища. Наприклад:
   ```bash
   pip install numpy
   ```

4. **Деактивація віртуального середовища**:
   Ви можете деактивувати віртуальне середовище, коли закінчите роботу з ним:
   ```bash
   deactivate
   ```

5. **Використання віртуального середовища у проекті**:
   Коли ви створюєте новий проект, вам слід активувати віртуальне середовище для цього проекту і встановити всі необхідні залежності. Таким чином, проект буде використовувати окреме середовище та буде незалежним від інших проектів.

`venv` - це корисний інструмент для керування залежностями та ізоляції проектів один від одного, що допомагає уникнути конфліктів та забезпечити чистий та ефективний процес розробки.

### 1. Розробка структури програми

Розробка консольної програми з інтерактивною взаємодією з користувачем та використанням віртуального середовища (venv) включає в себе наступні кроки:

1. **Створення віртуального середовища (venv):** Віртуальне середовище допомагає ізолювати вашу програму від глобального середовища Python і зберігати залежності проекту окремо. Ви можете створити його за допомогою команди:

   ```bash
   python -m venv myenv
   ```

   Де `myenv` - це ім'я вашого віртуального середовища.

2. **Активація віртуального середовища:** Після створення віртуального середовища його потрібно активувати:

   - В Windows:

     ```bash
     myenv\Scripts\activate
     ```

   - В macOS та Linux:

     ```bash
     source myenv/bin/activate
     ```

3. **Встановлення залежностей:** У віртуальному середовищі ви можете встановити всі необхідні залежності для вашої програми, використовуючи `pip`. Наприклад:

   ```bash
   pip install package_name
   ```

4. **Створення консольної програми:** Створіть Python файл для вашої програми. Ваша програма повинна взаємодіяти з користувачем через командний рядок, читати введені дані, обробляти їх і виводити результати.

5. **Запуск програми:** Після написання програми і збереження файлу, ви можете запустити його у віртуальному середовищі:

   ```bash
   python your_program.py
   ```

6. **Інтерактивна взаємодія:** Ваша програма повинна зчитувати введені дані від користувача, обробляти їх і виводити результати на консоль. Використовуйте функції `input()` для зчитування введення користувача та `print()` для виводу результатів.

7. **Завершення роботи програми та виходження з віртуального середовища:** Після завершення роботи вашої програми ви можете вийти з віртуального середовища:

   ```bash
   deactivate
   ```

Ось приклад простої консольної програми, яка запитує у користувача два числа і обчислює їх суму:

```python
def main():
    print("Ця програма обчислює суму двох чисел.")
    
    try:
        num1 = float(input("Введіть перше число: "))
        num2 = float(input("Введіть друге число: "))
    except ValueError:
        print("Помилка: введені дані не є числами.")
        return

    result = num1 + num2
    print(f"Результат: {result}")

if __name__ == "__main__":
    main()
```

Цей приклад створює віртуальне середовище, активує його, встановлює необхідні залежності (яких у цьому прикладі немає), запускає програму, і програма запитує два числа від користувача та обчислює їх суму.

Важливо пам'ятати, що це лише простий приклад. Ваша консольна програма може мати складнішу логіку та більше функцій для взаємодії з користувачем.

2. **Активація віртуального середовища:** Активуйте віртуальне середовище:

```python
from models.user import User
from services.user_service import UserService

class State(rx.State):
    name: str = ""
    age: str = ""
    users: list = []

            self.age = ""

            placeholder="Вік",
            value=State.age,
            on_change=State.set_age
        ),
```

#### Веб-додаток з Flask [https://flask.palletsprojects.com/en/stable/](https://flask.palletsprojects.com/en/stable/)

Приклад створення веб-додатку, що об'єднує REST API та веб-інтерфейс за допомогою Flask:

```python
from flask import Flask, request, jsonify, render_template, redirect, url_for
from flask_sqlalchemy import SQLAlchemy
from datetime import datetime

app = Flask(__name__)
app.config['SQLALCHEMY_DATABASE_URI'] = 'sqlite:///database.db'
app.config['SQLALCHEMY_TRACK_MODIFICATIONS'] = False
db = SQLAlchemy(app)

# Модель користувача
class User(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    name = db.Column(db.String(100), nullable=False)
    age = db.Column(db.Integer, nullable=False)
    created_at = db.Column(db.DateTime, default=datetime.utcnow)

    def to_dict(self):
        return {
            'id': self.id,
            'name': self.name,
            'age': self.age,
            'created_at': self.created_at.isoformat()
        }

# Створення таблиць
with app.app_context():
    db.create_all()

# Маршрути для веб-інтерфейсу
@app.route('/')
def index():
    users = User.query.all()
    return render_template('index.html', users=users)

@app.route('/user/add', methods=['GET', 'POST'])
def add_user():
    if request.method == 'POST':
        name = request.form.get('name')
        age = request.form.get('age')
        
        if name and age:
            user = User(name=name, age=int(age))
            db.session.add(user)
            db.session.commit()
            return redirect(url_for('index'))
            
    return render_template('add_user.html')

@app.route('/user/edit/<int:id>', methods=['GET', 'POST'])
def edit_user(id):
    user = User.query.get_or_404(id)
    
    if request.method == 'POST':
        user.name = request.form.get('name', user.name)
        user.age = int(request.form.get('age', user.age))
        db.session.commit()
        return redirect(url_for('index'))
        
    return render_template('edit_user.html', user=user)

@app.route('/user/delete/<int:id>')
def delete_user(id):
    user = User.query.get_or_404(id)
    db.session.delete(user)
    db.session.commit()
    return redirect(url_for('index'))

# REST API маршрути
@app.route('/api/users', methods=['GET'])
def api_get_users():

def api_create_user():

        return jsonify({'error': 'Invalid data'}), 400

    db.session.add(user)
    db.session.commit()
    return jsonify(user.to_dict()), 201

    user.name = data.get('name', user.name)
    user.age = data.get('age', user.age)
    db.session.commit()
    return jsonify(user.to_dict())
```
